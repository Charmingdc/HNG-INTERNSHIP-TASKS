🌟 **Muis Profile Card**

A sleek and dynamic personal profile card, crafted with HTML, CSS, and JavaScript. ✨ This project beautifully showcases essential personal information, social media links, hobbies, and a real-time clock, providing an elegant digital presence.

## Getting Started

### Installation

To get a copy of this project up and running on your local machine, follow these simple steps.

- **Clone the Repository**:
  ```bash
  git clone git@github.com:Charmingdc/HNG-INTERNSHIP-TASKS
  ```
- 📁 Navigate to the project directory:
  ```bash
  cd HNG-INTERNSHIP-TASKS/muis-profile-card/ # Adjust path if necessary
  ```

### Usage

This project is a static web page and does not require a server to run.

1.  🌐 Simply open the `index.html` file in your preferred web browser.
2.  The profile card will load, displaying Adebayo Muis's information, social links, hobbies, and a live updating clock.

## Features

- **Dynamic Real-Time Clock** ⏰: Displays the current time, updated every second, providing an interactive element.
- **User Profile Display** 👤: Clearly presents the user's avatar, name, and a concise professional biography.
- **Social Media Integration** 🔗: Provides direct, clickable links to various social platforms like GitHub, Twitter, LinkedIn, and Facebook for easy networking.
- **Personal Interests Overview** 💡: A well-organized section listing both hobbies and dislikes, offering a glimpse into the user's personality.
